🪣 Cấu Hình Amazon S3 & VPC Endpoint

Hướng dẫn Lab S3 VPC Endpoint:
• Gateway VPC Endpoint: Để trống ô Custom Endpoint URL. AWS Route Table sẽ tự định tuyến lưu lượng S3 qua Prefix List (pl-xxxxxx).
• Interface VPC Endpoint (PrivateLink): Nếu bật Private DNS thì để trống; nếu tắt Private DNS thì nhập URL dạng https://bucket.vpce-xxx.s3.ap-southeast-1.vpce.amazonaws.com.
